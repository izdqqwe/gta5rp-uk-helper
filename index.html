УК / ПК / ЗА / П1 / FIB Helper

Шпаргалка-помощник, пока учишь кодексы сам. Не заменяет знание — подсказывает статьи, чтобы свериться с текстом закона.

Как учить УК и ПК с этим помощником
УК — что сделал и какое наказание
  1. Убийство копа → 6.3; попытка → 17.1 (не 6.2.1)
  2. Уход / побег → 16.12
  3. Гос. оружие → 12.8.2 + 12.8.1 (вариант 3)
  4. ★ и срок — по таблице в ответе
ПК — как задержать и чьи права
  1. Задержание — до 1 часа (ст. 15)
  2. Порядок: наручники → удостоверение → Миранда (ст. 17)
  3. Звонок до 3 мин, адвокат, молчание (ст. 22)
  4. Гос. служащий → ОГП + руководство (ст. 19)
  5. Силa: присутствие → приказ → физ. → спец. → оружие (ст. 37)
ЗА — адвокат, договор, встреча, запрос
  1. Гос. адвокат — горячая линия, устный договор (ст. 8.1)
  2. Частный — приложение «Адвокаты» (ст. 8.2)
  3. Встреча с клиентом — до 10 мин (ст. 4.2)
  4. Гос. адвокат на КПЗ LSPD/LSCSD (ст. 4.2 п.ж)
  5. Неприкос гос. адвоката — ордер/суд/угроза жизни (ст. 3.2)
П1 — территории, доступ, цвета зон
  1. Белый — прилегающие + холл; жёлтый — охраняемые; красный — особо охраняемые
  2. Цель визита: CDWL, трудоустройство, заявление и т.д. (ст. 2)
  3. КПЗ = клетки + допросные + коридоры
  4. Адвокат на КПЗ — только по вызову, уйти за 5 мин
  5. FIB / Форт / Кайо — особо охраняемые (красные)
FIB — ФРБ, полномочия, неприкос
  1. Подчинение Генпрокурору (ст. 1.2)
  2. Обязан предъявить бейдж/жетон (ст. 4.3)
  3. Неприкос — ордер/суд/преступление/угроза жизни (ст. 17.7)
  4. Оцепление — мин. 2 копа на улицу (ст. 13.3)
  5. IB — надзор за госструктурами (ст. 9.с)

Схема обучения: опиши ситуацию → нажми «Подобрать» в режиме УК + ПК → прочитай статьи → сверь с полным текстом кодекса → попробуй сам сформулировать RP без подсказки.
