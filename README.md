# GTA 5 RP — УК / ПК / ЗА / П1 / FIB / НП San-Andreas Helper

Подбор статей **Уголовного**, **Процессуального** кодексов, **Закона об адвокатуре**, **Приложения №1**, **ФРБ** и **Закона о неприкосновенности** штата San-Andreas.

- **УК** — преступления, ★, срок, текст для RP
- **ПК** — задержание, Миранда, права, боло, стадии силы
- **ЗА** — адвокатура: договор, встреча 10 мин, КПЗ, неприкос, запрос
- **П1** — закрытые/охраняемые территории, доступ, цвета зон, КПЗ
- **FIB** — ФРБ + Устав FIB: полномочия, неприкос, патруль, бейдж, видео, выговоры
- **НП** — неприкосновенность: список лиц, кортеж, USSS, ордер AI
- **УК + ПК** — оба сразу
- **Ситуации** — пошаговые инструкции (как каффать, адвокат, неприкос, прокурор и т.д.)
- **Законы** — полные тексты УК, ПК, ЗА, П1, FIB, устав FIB, НП (как ты присылал)

## Онлайн 24/7 (GitHub Pages)

Сайт: https://izdqqwe.github.io/gta5rp-uk-helper/

Запусти **`publish-github.bat`** — обновит репозиторий на GitHub.

## Быстрый запуск (без сервера, всегда работает)

**Дважды кликни `open.bat`** — откроется программа в браузере.

Или открой **`standalone.html`** — Python и `run.bat` **не нужны**.

### Ярлык на рабочий стол

Запусти **`create-shortcut.bat`** — появится ярлык **UK Helper** на рабочем столе.

### Автозапуск при входе в Windows

Запусти **`install-autostart.bat`** один раз — программа будет открываться сама при включении ПК.

## Как пользоваться

Введи ситуацию текстом, например:

```
убил гос сотрудника, пытался скрыться с места, было гос оружие
```

Нажми **«Подобрать статьи»** — получишь таблицу статей, розыск (★), наказание и текст для зачитывания в RP.

## Настройки

- **Вариант 3** — при гос. оружии ставит **и 12.8 ч.2, и 12.8.1** (как на многих серверах)

## Структура

- `data/articles.json` — база статей УК
- `data/pk_articles.json` — ключевые статьи ПК
- `data/adv_articles.json` — ключевые статьи ЗА (адвокатура)
- `data/p1_articles.json` — ключевые статьи П1 (территории)
- `data/guides.json` — пошаговые ситуации
- `data/tags.json` — ключевые слова УК
- `law-engine.js` — логика УК (браузер)
- `pk-engine.js` — логика ПК (браузер)
- `adv-engine.js` — логика ЗА (браузер)
- `p1-engine.js` — логика П1 / территории (браузер)
- `fib-engine.js` — логика FIB / ФРБ и Устав FIB (браузер)
- `np-engine.js` — логика НП / неприкосновенность (браузер)
- `src/matcher.py` — логика УК (Python)
- `src/app.py` — веб-сервер

## Добавление статей

1. Добавь статью в `data/articles.json`
2. При необходимости — ключевые слова в `data/tags.json`
3. Добавь правило в `src/matcher.py`

## Ограничения

- Работает по **ключевым словам**, не как живой адвокат
- **КоАП** пока не подключён
- ПК пока в сокращённом виде (задержание, права, процедура) — полный текст можно дополнять
- Для сложных случаев описывай ситуацию подробнее
